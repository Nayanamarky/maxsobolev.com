# Портфолио — CG/VFX Production Supervisor

Статический сайт на Astro. Двуязычный: RU по адресу `/`, EN по `/en`.

## Документы решений

- `Задачи разработки/01_concept.md` — концепция, визуальный язык, палитра.
- `Задачи разработки/02_состояние.md` — что сделано, структура, как добавить проект, что дальше.
- `Задачи разработки/03_список_работ.md` — сырой список реальных работ, открытые вопросы по категориям.

Решения фиксируются в этих файлах до написания кода.

## Правила

- Тексты интерфейса — только в `src/i18n/ui.ts`. Строк в компонентах быть не должно: обе локали правятся в одном месте.
- Проекты — файлы в `src/content/projects/`. Добавление проекта не требует правки кода.
- Визуальный язык (near-black, скраб, таймкод) описан в `01_concept.md`. Менять палитру и шрифты — только по явной просьбе автора.
- Прототип в `work/portfolio-prototype.html` — исходная точка, не трогать: это референс, а не рабочий файл.
- Медиа не хранится в репозитории (кроме `public/placeholder/` — заглушки). Видео и картинки уедут на внешний хостинг.

## Команды

```
npm run dev      локальный сервер, http://localhost:4321
npm run build    сборка в dist/
```
