**Работает:**

- Роутинг главная → проект: клик по плитке открывает `/project/<id>` (и `/en/project/<id>`), внизу навигация «пред / след».
- 22 реальные работы перенесены в контент-файлы (коммит `0cafede`), все со статусом `draft: true`.
- Сборка: 8 страниц, ошибок нет. Страниц мало и сетка пустая — потому что все работы черновики.

| Решение | Выбор | Почему |
|---|---|---|
| Сборка | Astro 7, статическая генерация | Контент отдельно от кода; i18n из коробки; на выходе обычный HTML, фреймворка в браузере нет |
| Языки | RU по умолчанию (`/`), EN с префиксом (`/en`) | Заложено сразу — добавлять потом дорого |
| Тексты интерфейса | `src/i18n/ui.ts` | Все строки в одном файле, в компонентах строк нет |
| Проекты | `src/content/projects/*.md` | Один проект — один файл; схема проверяется на сборке |
| Домен | `maxsobolev.com` | Куплен 19 августа 2026 на reg.ru. Канонический адрес — `https://maxsobolev.com`, прописан в `astro.config.mjs` |
| Хостинг сайта | Cloudflare Pages | Решено 20 августа 2026. Бесплатно, деплой из git на каждый push, SSL и CDN из коробки — для чисто статического сайта без бэкенда меньше всего ручной работы. Был вариант держать на своём VPS (aeza.net) — отклонён: сервер простаивает, а ради статики разворачивать nginx/certbot/деплой-скрипт вручную незачем |
| Видео | Bunny Stream | Решено 20 августа 2026. Дешёвый тариф по хранению+трафику, свой iframe-плеер |
| Картинки и лёгкие превью-клипы | Bunny CDN (Storage zone + Pull zone) | Решено 20 августа 2026. Тот же аккаунт, что и Bunny Stream — один вендор на все медиа вместо трёх. В репозиторий не кладём: медиа туда не хранится в принципе (см. правило в `CLAUDE.md`) |

## Структура

```
Portfolio_site/
├── Задачи разработки/        документы решений
├── work/                     прототип из чата (портфолио-прототип.html)
├── public/placeholder/       кадры-заглушки, 6 штук
└── src/
    ├── content/projects/     ← ПРОЕКТЫ: один файл = один проект
    ├── i18n/ui.ts            ← ТЕКСТЫ интерфейса, RU и EN
    ├── styles/global.css     весь CSS, перенесён из прототипа
    ├── components/           Header, Filters, Tile, ToTop
    ├── layouts/              Base, Home, ProjectPage, StubPage
    ├── lib/projectPaths.ts   маршруты проектов + соседи
    └── pages/                маршруты: /, /en, /project/[id], /en/project/[id]
```

## Как добавить проект

Создать файл `src/content/projects/имя-проекта.md`:

```markdown
---
title: "Название"
client: "Клиент"
year: 2026
categories: [vfx, character]  # character | vfx | motion2d | neuro
production: "shoot"           # shoot | cg — необязательно
cover: "/placeholder/frame-01.jpg"
order: 20260315                # дата ГГГГММДД, больше — новее и выше в сетке
draft: false                  # true — не показывать
---

Текст ниже — Markdown, это описание проекта и, если нужно, `## Credits`.
```

Про `videos` (ролики с плеем на странице проекта) — см. `04_страница_проекта.md`.

### Порядок и как его менять

`order` — дата в формате `ГГГГММДД` (например `20250315`), больше значит новее и
выше/левее в сетке (изменено 20 августа 2026 — раньше было произвольное число с
шагом 10, потом 100; сортировка в коде тоже развёрнута под это, см. `Home.astro` и
`projectPaths.ts`). Пока у большинства проектов известен только год — день и месяц
проставлены заглушкой `01.01` (`20250101`), поправить можно в любой момент, просто
поменяв цифры. Это не создаёт проблем с зазорами: дата — по сути просто большое
число, места между любыми двумя датами всегда достаточно.

Имя файла становится адресом страницы: `unity.md` → `/project/unity`.
Если обязательное поле пропущено — сборка остановится и скажет какое.
