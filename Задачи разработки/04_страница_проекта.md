# 04 — Страница проекта

Записано: 19 августа 2026. Решения из обсуждения в чате.

## Структура сверху вниз

1. **Герой** — кадр со скрабом (как на плитке главной) + кнопка плей поверх, если есть видео.
2. **Заголовок** — название, роль автора / клиент / год / категории / съёмка-full CG.
3. **Мой вклад** — текст из тела файла проекта (Markdown). Тут же, если нужно, `## Credits`.
4. **Ещё ролики** — если у проекта их больше одного, список под заголовком «Мой вклад», каждый своим блоком со скрабом и плеем.
5. **Пред / след** — уже есть, не меняется.

## Герой и видео: скраб → плей

Не автоплей. Последовательность:

1. По умолчанию — кадр (`cover`/постер ролика) со скрабом: курсор панорамирует по кадру, бежит таймкод. Тот же приём, что на плитках главной.
2. Поверх — кнопка ▶, если у видео есть `embed`-ссылка.
3. Клик по плею — кадр меняется на `<iframe>` с видео (Vimeo/Bunny), начинается воспроизведение.
4. Если `embed` не указан (видео ещё не залито) — кнопки плей нет, просто кадр со скрабом. Страницу можно свёрстывать и наполнять текстом до того, как появится видео.

Так же устроен любой ролик в списке «Ещё ролики» — свой скраб, своя кнопка плей, свой `embed`.

`embed` понимает два вида ссылок: прямой файл (`.mp4`/`.webm`/`.mov`/`.m3u8`, локальный из `media-local/` или с CDN) — тогда это обычный `<video controls>`; любой другой адрес — считается ссылкой на встраиваемый плеер (Vimeo/Bunny) и идёт в `<iframe>`. Определяется по расширению в ссылке, руками ничего указывать не нужно.

## Мой вклад / кредиты — это Markdown-тело файла

Отдельного поля для кредитов нет: у проектов слишком разная структура (где-то соло, где-то большая команда), под это не нужна жёсткая схема. Пишется прямо в файле проекта под frontmatter:

```markdown
---
title: "Черкизово"
...
---

Работал супервайзером по CG на два ролика для Черкизово...

## Credits
- Режиссёр — Имя Фамилия
- Продюсер — Имя Фамилия
```

Рендерится как обычный HTML: заголовки, абзацы, списки, картинки (`![подпись](/placeholder/frame-01.jpg)`). Когда появятся кадры «до/после» — вставляются просто как две картинки подряд в тексте, без отдельного компонента. Отдельный слайдер до/после — не сейчас, в открытых вопросах ниже.

## Несколько роликов на проекте (Черкизово, Wink, H-box…)

Список роликов друг под другом. Каждый ролик — `label` (короткая подпись: «Кат 1», «30 сек», что угодно) + `embed` + свой `poster`, необязательный (если нет — берётся `cover` проекта).

## Изменения схемы (`content.config.ts`)

```ts
videos: z.array(z.object({
  label: bilingual.optional(),   // подпись ролика, если их несколько
  embed: z.string(),             // Vimeo/Bunny-ссылка ИЛИ прямой .mp4/.webm/.mov/.m3u8
  poster: z.string().optional(), // кадр-превью; если нет — cover проекта
})).optional(),
```

Если поле `videos` не указано вовсе — герой остаётся кадром без плея (текущее поведение всех 12 заглушек не ломается).

## Что не меняется

- Плитки на главной, скраб, фильтры — без изменений.
- Отдельного поля `role` в схеме нет: роль автора на всех проектах одна — CG/VFX Supervisor,
  она уже написана в шапке сайта под именем. Дублировать её на каждой странице проекта незачем.
