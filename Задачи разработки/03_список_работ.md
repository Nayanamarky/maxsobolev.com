## Что из этого следует

**Категории фильтра надо менять.** Сейчас в коде `cg | vfx | realtime | direction`
(фильтры CG / VFX / REALTIME / SUPERVISION). В реальных работах таких категорий нет:
есть **персонажка**, **VFX**, **2D motion**, **нейронка**. «Realtime» и «Supervision»
не встречаются ни разу, «CG» описывает почти всё и потому ничего не отделяет.

**Осей на самом деле две.** «Персонажка / VFX / 2D motion / нейронка» — это *что делали*.
«Съёмка / full CG» — это *на чём*. Решено: фильтр только по типу, съёмка/full CG —
факт на странице проекта, не кнопка фильтра.

**Раскладка по типам:** персонажка — 11, VFX — 6, 2D motion — 4, нейронка — 3.
Ряд из четырёх кнопок наполнен неравномерно, но каждая что-то отсекает.

## Решено (19 августа 2026)

- **Категории фильтра** — одна ось, по типу: `character` (персонажка), `vfx`,
  `motion2d` (2D motion), `neuro` (нейронка). Внесено в `content.config.ts`,
  `i18n/ui.ts`, `Filters.astro`. Съёмка/full CG в фильтр не идёт — это факт
  на странице проекта.
- **Поле `client`** — остаётся брендом, как сейчас. Студия не добавляется.
- **Проекты с несколькими роликами** — одна страница проекта, ролики внутри
  (Черкизово, Перекрёсток, Wink, Вкусовые сосочки, H-box). Учесть при спеке
  страницы проекта: нужен блок-галерея на несколько видео, не один герой-ролик.
