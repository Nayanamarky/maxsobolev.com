# 01 — Концепция

**Проект:** сайт-портфолио. Максим Соболев, CG/VFX Production Supervisor.
**Референс:** kins.tv — сетка проектов, тёмный минимализм.
**Источник:** выжимка из чата-концепции + `work/portfolio-prototype.html` (рабочий прототип главной).

## Задача

Показать проекты так, чтобы язык интерфейса читался как язык ремесла: таймкод, скраб, кадр. Не «сайт про дизайн», а монтажный стол.

## Главная страница (спроектирована, прототип есть)

- **Шапка:** имя слева (MAX SOBOLEV / CG · VFX SUPERVISOR), бургер справа → выпадающее меню: Обо мне, Контакты, Посты из ТГ. Внизу меню — строка TELEGRAM · BEHANCE · IMDB.
- **Фильтры категорий:** ВСЕ / CG / VFX / REALTIME / SUPERVISION. Реально фильтруют сетку (не декор).
- **Сетка:** 3 колонки → 2 на планшете (≤900px) → 1 на телефоне (≤560px). Гэп 1px, линии — фон сетки.
- **Плитка при наведении:** курсор панорамирует по кадру (лёгкий zoom), название/клиент выезжают снизу. Таймкод, полоса перемотки и затемнение кадра — были фейковыми декоративными элементами, убраны 20 августа 2026 (см. открытый вопрос про настоящий скраб в `02_состояние.md`).
- **Кнопка «наверх»** появляется после ~400px прокрутки.

## Страница проекта (открытый пункт — не спроектирована)

Черновой каркас:

1. Полноэкранный герой — видео или кадр.
2. Название + роль / клиент / год.
3. Блок «мой вклад».
4. Череда кадров и breakdown'ов: до/после, пассы.
5. Кредиты.
6. Пред / след проект.

## Стиль

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#0b0c0e` | near-black фон |
| `--panel` | `#131519` | плитки, меню, кнопки |
| `--line` | `#23262c` | линии сетки, обводки |
| `--ink` | `#e9ebee` | основной текст |
| `--dim` | `#7a8089` | вторичный текст, лейблы |
| `--scrub` | `#d7e3ea` | холодный «мониторный» акцент: таймкод, полоса |

Шрифты: **Space Grotesk** (заголовки, интерфейс) + **JetBrains Mono** (таймкод, лейблы, служебное).
Сигнатура: таймкод и скраб как визуальный язык.

## Медиа — технические решения

- **Видео не самохостить.** Vimeo Pro или Bunny Stream / Cloudflare Stream. Опционально VK Video для РФ.
- **Картинки и постеры** — Cloudflare R2 или Bunny CDN. Не в репозитории.
- **Скраб на плитке:** реальный `<video>`-seek тяжёлый. Решение — спрайт из ~20 кадров (почти бесплатно) либо hover-play лёгкого превью.
